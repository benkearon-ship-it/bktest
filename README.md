# Scotiabank Landing Page - Harness Continuous Delivery

A custom landing page designed for Scotiabank to promote Harness Continuous Delivery platform.

## Overview

This landing page highlights the benefits of Harness Continuous Delivery for enterprise banking institutions, with a focus on:

- **Enterprise Security**: Bank-grade security and compliance features
- **Rapid Deployment**: Automated verification and instant rollback capabilities
- **Complete Visibility**: Real-time insights into deployment metrics
- **Intelligent Automation**: AI-powered deployment pipelines
- **Multi-Cloud Ready**: Support for AWS, Azure, GCP, and on-premises
- **Cost Optimization**: Intelligent resource management

## Features

### Sections

1. **Hero Section**: Eye-catching introduction with key statistics
2. **Benefits Section**: Six key benefits for banking institutions
3. **Features Section**: Detailed showcase of Harness capabilities
4. **Case Study**: Social proof from financial services industry
5. **Contact Section**: Multiple CTAs for engagement
6. **Footer**: Additional resources and links

### Design

- Modern, professional design using Scotiabank's red branding (#EC1C24)
- Fully responsive layout optimized for desktop, tablet, and mobile
- Smooth animations and hover effects
- Accessible and user-friendly navigation

## Customization

### Colors

The landing page uses CSS custom properties (variables) defined in `styles.css`:

- `--scotiabank-red`: #EC1C24 (Scotiabank brand color)
- `--scotiabank-dark`: #1F2937 (Dark backgrounds)
- `--harness-blue`: #0066CC (Harness accent color)

### Content

All content can be easily modified in `index.html`:

- Update statistics in the hero section
- Modify benefit cards
- Change feature descriptions
- Update contact CTAs

## Call-to-Actions

The landing page includes three primary CTAs:

1. **Schedule a Demo**: Links to Harness demo booking
2. **Contact Sales**: Links to Harness sales contact
